## Fabryka

Zmiany w tym repo robi taśma fabryki: issue z etykietą `ready` → plan → PR z gałęzi `factory/*` → recenzja → ocena ryzyka.

Gdy ktoś opisuje pomysł albo zmianę („mam pomysł”, „chcę, żeby…”, „dodaj…”), użyj skilla `spec-writer`: spisz spec i po potwierdzeniu załóż issue z etykietą `ready`. Nie implementuj sam w tej sesji, chyba że właściciel wprost o to poprosi.
